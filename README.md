## The word

**almost**

One word is all an ex needs. "Almost" is the whole relationship in six
letters: almost the one, almost enough, almost made it. It is funny
because it is small, and it stings because it is true — the entrant
plainly knows it. It lands instantly, needs no explanation, and no
near-synonym ("nearly", "close") carries the same edge. Everyone has
been an "almost", or had one.

## How it works

`main.py` writes exactly that one word — nothing else, no trailing
newline — to `/output/entry.txt`. The program is fully deterministic:
same output on every run. No network, no randomness, no secrets.

```sh
python3 main.py
cat /output/entry.txt   # almost
```
